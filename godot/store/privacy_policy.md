# Kebijakan Privasi Cozy Kost

Terakhir diperbarui: 21 November 2026

Cozy Kost ("Game") dikembangkan oleh KelolaPro. Kebijakan ini menjelaskan data apa yang kami kumpulkan.

## Data yang disimpan di perangkat
Progres permainan (uang di game, level, kamar, Diamond) disimpan di perangkatmu. Data ini tidak dikirim ke server kami.

## Pembelian dalam aplikasi
Pembelian Diamond diproses oleh Google Play. Kami tidak menerima data kartu atau rekening pembayaranmu.
Untuk memastikan pembelian sah, Game mengirim ke server verifikasi kami: ID produk, token pembelian dari Google Play,
nomor pesanan, dan ID acak yang dibuat Game (tidak terhubung dengan nama, email, atau identitasmu).
Data ini disimpan untuk mencegah pembelian dipakai dua kali dan untuk menangani pengembalian dana.

## Yang tidak kami kumpulkan
Kami tidak mengumpulkan nama, email, kontak, lokasi, foto, atau ID iklan. Game tidak menampilkan iklan.

## Anak-anak
Game ditujukan untuk pengguna berusia 13 tahun ke atas.

## Menghapus data
Menghapus aplikasi akan menghapus progres di perangkat. Untuk meminta penghapusan catatan pembelian, hubungi kami.
