# Cozy Kost - Landlord Simulator — Demo Web

Game simulasi juragan kost bergaya cozy, dibuat dengan Godot 4.7.

**Main di sini:** https://illuminaldi.github.io/kost-simulator/

Repo ini hanya berisi hasil ekspor web (`index.html`, `index.wasm`, `index.pck`, dll.) yang disajikan lewat GitHub Pages.
Paling nyaman dimainkan di HP dalam posisi potret. Progress tersimpan di browser.

## Source code

Project Godot 4.7 ada di folder [`godot/`](godot/). Buka `godot/project.godot` di Godot 4.7, lalu ekspor preset **Web** ke root repo ini untuk memperbarui demo.
